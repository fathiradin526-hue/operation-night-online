# عملیات شبانه — نسخه آنلاین

این پوشه یک پروژه Node.js است؛ فایل HTML به‌تنهایی برای حساب‌های مشترک، اتاق آنلاین و پنل مدیریت کافی نیست. سرور باید اجرا شود.

## قابلیت‌ها
- بازی سه‌بعدی اصلی فایل آپلودشده حفظ شده است.
- ساخت حساب و ورود با رمز عبور روی سرور.
- شناسه عددی خودکار برای هر حساب و موجودی اولیه ۰ سکه.
- پنل مدیریت در مسیر `/admin.html`، با افزایش/کاهش سکه و تاریخچه تراکنش.
- ساخت اتاق و ورود با کد؛ همگام‌سازی جای بازیکن‌ها به‌صورت زنده.
- ذخیره داده‌ها در `data/db.json`.

## اجرای محلی
1. Node.js نسخه 18 یا جدیدتر نصب کن.
2. ترمینال را در همین پوشه باز کن و اجرا کن: `npm install`
3. متغیرهای محیطی زیر را تنظیم کن و مقادیر امن خودت را بگذار:
   - `TOKEN_SECRET`: رشته تصادفی طولانی (حداقل ۳۲ نویسه)
   - `ADMIN_USERNAME`: نام کاربری مدیر
   - `ADMIN_PASSWORD`: رمز قوی مدیر
   - `DATA_DIR`: مسیر ذخیره داده‌ها (اختیاری؛ پیش‌فرض `./data`)
4. اجرا: `npm start`
5. بازی: `http://localhost:3000` — پنل مدیریت: `http://localhost:3000/admin.html`

## استقرار
در سرویس میزبانی، فرمان اجرا `npm start` باشد و متغیرهای محیطی بالا را تنظیم کن. فایل `.env.example` فقط نمونه است؛ آن را به‌عنوان رمز واقعی استفاده نکن. مقادیر واقعی را در بخش Environment Variables پنل میزبان وارد کن و رمز مدیر را در کد عمومی یا GitHub ننویس. برای ماندگاری اطلاعات پس از تعویض نسخه یا استقرار مجدد، باید سرویس میزبانی **دیسک/فضای ذخیره‌سازی دائمی** ارائه کند و `DATA_DIR` به آن مسیر اشاره کند. اگر میزبان فایل‌های محلی را بعد از استقرار مجدد پاک کند، فایل JSON به‌تنهایی ذخیره دائمی تضمین‌شده نیست؛ در آن حالت باید دیتابیس خارجی/دائمی متصل شود.

## محدودیت مهم این نسخه
اتاق آنلاین و نمایش موقعیت بازیکن‌ها همگام می‌شود، اما این هنوز سرور رقابتی ضدتقلب نیست: آسیب سلاح‌ها، کشتن دشمن‌ها و کل منطق مبارزه برای همه بازیکن‌ها به‌صورت authoritative مشترک پیاده‌سازی نشده است. همچنین برای آنلاین بازی کردن باید این پروژه روی یک سرور Node.js اجرا شود؛ باز کردن مستقیم فایل HTML کافی نیست.
